# TPS Optimization Documentation

This directory contains AI-generated and human-reviewed optimization knowledge for the Starcoin TPS benchmark.

## Directory Structure

```
docs/
├── README.md                    # This file
├── OPTIMIZATION_KNOWLEDGE.md    # Learned optimization strategies and insights
├── BENCHMARK_HISTORY.md         # Historical benchmark results summary
├── LESSONS_LEARNED.md           # What worked, what didn't, and why
└── adr/                         # Architecture Decision Records
    └── 000-template.md          # ADR template
```

## For AI Agents

When working on TPS optimization:

1. **Read First**: Always read `OPTIMIZATION_KNOWLEDGE.md` before suggesting optimizations
2. **Update After**: After successful optimization, update the relevant docs
3. **Record Decisions**: Create ADRs for significant architectural changes
4. **Track History**: Append benchmark results to `BENCHMARK_HISTORY.md`

## For Human Reviewers

- All AI-generated content should be reviewed before merging
- Knowledge in these docs is shared across the team and all AI agents
- Keep content concise and actionable
